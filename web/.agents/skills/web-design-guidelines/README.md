# UI Design Guidelines - Da Nang Food Safety Management System

## Introduction

This documentation provides design standards for the admin dashboard of the Food Safety Management and Notification System for Da Nang City.

## Design Philosophy

- **Modern & Minimal**: Clean interface, focused on content
- **Professional**: Suitable for administrative work, not flashy
- **Easy to Use**: Prioritizes daily admin user experience
- **Trustworthy**: Green as primary color represents safety and reliability
- **Gentle**: Subtle colors, not harsh, easy on the eyes for long periods

## Tech Stack

- **Framework**: Next.js 14+ (App Router)
- **Styling**: Tailwind CSS 3+
- **Component Library**: shadcn/ui
- **Icons**: Lucide React
- **Charts**: Recharts or Chart.js

## How to Use

1. Read **UI_STYLE_GUIDE.md** to understand the overall design philosophy
2. Reference **COLORS_AND_SURFACE.md** and **TYPOGRAPHY.md** when starting the project
3. Apply **LAYOUT.md** for page structure
4. Use **COMPONENTS.md** as reference when coding components
5. Check **MOTION_AND_ACCESSIBILITY.md** before finalizing

## Application Rules

- **Consistency**: Follow guidelines throughout the entire system
- **Flexibility**: Can adjust slightly if there's a valid reason
- **Updates**: Review and update guidelines when necessary
- **Sharing**: Ensure the entire team understands and applies correctly
